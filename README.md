GEOAnalyze

main.py的功能是：
===

# 

# 1\. 从数据库中获取指定日期（如2025-12-17）被提及最多的键盘品牌；  



# 2\. 查询该品牌在“keyboard”类别下的所有外部引用（如网页链接）；  



# 3\. 按来源类型（如 Gov、Media 等）对链接进行分类采样（每类最多5个）；  



# 4\. 使用爬虫批量抓取采样得到的链接的 HTML 内容并保存到本地crawhtml目录；  



# 5\. 打印各来源已保存的文件路径，用于验证爬取结果。

# 

# > 注：大模型分析和生成建议报告的部分尚未实现，后续根据业务情况再继续实现。



test\_analyze\_html\_by\_domain.py的功能是根据domain类型如reddit，采样该域名下的若干url，并且进行大模型分析

htmlbyhuman的功能是，手动粘贴爬取了10个网页，利用大模型进行分析，生成markdown格式的广告投放建议
